# 18 November 2026: six stories that defined the day

One image summing up the world news of Wednesday 18 November 2026, drawn as a
newspaper front page. `main.ts` (Node 22, standard library only) copies
`entry.png` to the output directory; `draw_image.py` is the PIL script that
drew the page, so every letter is crisp — no image-generator text anywhere.

   Sullivan, giving Democrats the US Senate majority.
   (Associated Press; NPR News Now, 18 Nov)

   aircraft comes down in Siberia's Kemerovo region. (Daily Baku, 18 Nov)
6. **Ebola cases more than double** — the DR Congo outbreak passes 11,000
   cases and 5,400 deaths, the UN says; children hit hardest.
   (One Turn; Horizon, 18 Nov)
